\section{Descrição do Sistema}
Este documento apresenta o esquema de conexões para o controlador de motor de passo NEMA23 usando ESP32 e driver DM556. O sistema inclui funcionalidades avançadas como homing com interruptor de limite, salvamento de posições e controle serial.

\section{Configuração do DM556}

O driver DM556 deve ser configurado com os seguintes DIP switches para microstepping 1/256:

\begin{itemize}
\item SW1 (MS1): ON
\item SW2 (MS2): ON
\item SW3 (MS3): ON
\item SW4-SW8: Consulte o manual do DM556 para corrente e outras configurações (geralmente OFF para padrão)
\end{itemize}

\section{Notas Importantes}

\begin{itemize}
\item Verifique a polaridade da fonte de alimentação antes de conectar
\item As conexões ENABLE e HOME são ativas baixas (LOW = habilitado/acionado)
\item Ajuste os pinos GPIO no código se a fiação for diferente
\item Garanta que a corrente da fonte seja adequada para o motor NEMA23
\item Use cabos de boa qualidade para evitar interferências
\item O interruptor de limite deve ser conectado com pull-up interno do ESP32
\item Para homing, mova o motor na direção apropriada até o interruptor ser acionado
\end{itemize}
